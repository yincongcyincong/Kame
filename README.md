# 星星学园

星星学园是以动画角色互动为主的桌面应用。打开即可选择《超级飞侠》《宇宙护卫队》《拉布拉多警长》或《宝贝JOJO》，也可以从首页创建自定义角色游戏。

完成预设任务会获得三枚徽章，进度保存在 SQLite。以前分开记录的同一个动画任务会合并显示为一个完成记录。

## 运行

需要 Make、Node.js、Go 1.23 或以上，以及支持 CGO 的 C 编译器（macOS 可用 Xcode Command Line Tools）。

```sh
make
```

首次运行会联网安装依赖，然后构建 React 和 Go，并启动 Electron。可用 `make build` 只构建，或用 `make frontend`、`make backend` 单独构建。执行 `make test` 可检查题库和本地存档逻辑。

Electron 会启动仅监听本机回环地址的 Go 服务。SQLite 存放在 Electron 用户数据目录。浏览器预览可运行 `npm run preview`，再打开服务打印的本地地址。浏览器预览默认在项目目录使用 `learning.db`。

## 学习伙伴小星

桌面版和网页预览的右侧均可打开「模型设置」。填写 OpenAI 兼容的 Chat Completions API 地址、对应的模型名和 API Key。例如，基地址可写成 `https://example.com/v1`，也可以填写含 `/chat/completions` 的完整地址。无需密钥的本机模型可留空。远程模型需使用 HTTPS。

可以打字，也可点「系统听写」定位到输入框，再使用电脑设定的听写快捷键。macOS 在「系统设置 → 键盘 → 听写」开启，Windows 使用 Windows + H。确认转写文字后点「发送」。模型回复默认用系统的本地中文语音朗读，可关闭自动朗读或逐条重听。

每条请求会把近几轮对话和任务徽章、已完成任务数、当前游戏及站点进度发往你配置的模型地址。应用不会录制或发送音频，也不会把聊天记录和密钥写入本地数据库。刷新页面或重启后需要重新配置。

聊天框底部的「朗读设置」可以选本地中文音色、调语速并试听。macOS 可在「系统设置 → 无障碍 → 阅读与朗读」下载更多中文声音。如果下载后列表还未更新，重新打开应用。

想连续语音对话时，可以在「系统听写」里打开「免按发送」。转写文字停止更新约两秒后会自动发送。应用根据操作系统输出到输入框的文字判断停顿。听写是否持续由系统决定，系统已停止听写时需要再按一次听写快捷键。退出听写模式后可恢复手动发送。

## 动画角色任务

目前有 **29 个预置游戏**，分布在 4 部动画中。预置游戏可离线游玩，完成进度存入 SQLite。

| 动画 | 预置游戏数 | 玩法 |
| --- | ---: | --- |
| 超级飞侠 | 5 | 世界机场光球对决、开飞机送快递、听声送包裹、乐迪接包裹、双机接力 |
| 宇宙护卫队 | 6 | 救援基地光球对决、开救援车搭桥、照亮山洞、护卫队跳远赛、接住能量晶石、管道抢修 |
| 拉布拉多警长 | 7 | 3 个 2D 走访推理案件、案发现场回放、听音寻踪、接住证物袋、脚印追踪 |
| 宝贝 JOJO | 11 | 喂饭、刷牙、搭积木、梳头、开早餐店、搭小车乐园、玩具小卖部、汉字修理铺、接金币、节奏乐队、小小天平 |

在首页选择动画和任务，用 WASD、方向键或屏幕按钮在 2D 地图上移动。走近另一位角色后，台词会显示在角色旁的气泡里，操作仍在地图下方，可以听口供、递道具、送包裹、搭桥或一起解决任务。超级飞侠和宇宙护卫队的靶场只有玩家选中的角色和当前对手。每局依次挑战三位对手，击败一位后下一位才登场。《超级飞侠》有黑金小子、金小薇和比利威利，《宇宙护卫队》有霹雳、黑洞三角龙号和银河剑龙号。用空格、瞄准地图点击或「发射光球」按钮攻击。反派会预警并反击。被光球击中才在地图下方的护盾区随机出题，答对可恢复护盾。选角色时可选 1～6 年级，每个年级的语文、数学、英语各有 50 题，另有 20 道常识题。同一局优先出未见过的题。击中反派就解锁下一处挑战。警长任务在地图上走访警员和羚羚羊，再比对线索。宝贝 JOJO 的生活任务使用动画剧照与道具动画，支持中英词汇。

跳远时按住空格或屏幕上的蓄力按钮，接近满格时松开。超过满格要重新蓄力，每一次有效起跳都会和发挥在 80%～95% 的电脑对手比较距离。

接物任务可选角色和题目年级。按 A / D、左右方向键或屏幕方向按钮移动，也可以用手指或鼠标直接点地面。漏接时暂停并抽题，答对才继续。

双机接力、管道抢修、脚印追踪、节奏乐队和小小天平也可选题目年级。挑战失败时在场景内答题，答对后重试出错的步骤。

以上数量只统计预置游戏。自定义角色游戏由 AI 按需生成。

从首页点「自定义角色游戏」，选动画和角色，也可以在动画任务页点「自定义任务」。可以直接打字，也可以点「系统听写」并用电脑的听写快捷键口述点子。确认文字后，点「生成任务并开始」。生成会把动画、角色和点子发给右侧已配置的模型。模型返回的装箱和排序任务通过格式与可玩性校验后进入地图，靠近伙伴再开始第一站。生成的任务可在当前页面重玩，右侧学习伙伴也能看到当前角色和任务进度。

预置游戏使用 2D 画面和本地角色图，无需 WebGL。角色资料图和动画剧照来自上面的公开来源。

首次配置模型前，由家长用环境变量启动应用，例如 `K_GAME_PARENT_PIN='自行设置至少六位的密码' make`。聊天栏的模型设置需要先验证这个密码。模型回复和生成任务会再调用一次所选模型审核内容，审核失败时使用本地安全提示或引导返回预设任务。模型审核存在误判的可能。
